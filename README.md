# California Hospital Revenue Cycle and Claims Denial Analysis

## Project Overview

This project analyzes a synthetic California hospital dataset covering
January through March 2025. The dataset includes hospital encounters,
clinical activity, providers, claims, billing, payments, and claim
denials.

SQL will be used to evaluate operational and financial performance,
identify the primary causes of claim denials, measure their financial
impact, and develop recommendations for hospital leadership.

## Business Problem

Hospital leadership wants to better understand Q1 2025 performance,
with particular attention to claim denials, reimbursement, outstanding
balances, and differences across departments and insurance payers.

## Project Objectives

1. Validate the quality and relational integrity of the data.
2. Calculate hospital financial and operational KPIs.
3. Measure claim denial rates and denied dollar amounts.
4. Identify the most frequent and costly denial reasons.
5. Compare performance across payers, departments, providers, and
   service categories.
6. Develop recommendations to reduce preventable denials and improve
   reimbursement.

## Dataset

The CA Hospital Dataset – Q1 2025 is a synthetic dataset obtained from
Kaggle. It contains more than 126,000 records across nine integrated
tables.

The original raw data is not stored in this repository.
